# dst10-e-booklet

Page-flip e-booklet for **Dance Series Track 10: Dance the Night Away**, presented by the Lasallian Pointes N' Flexes Dance Company (LPNFDC).

## Viewing

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to host it online.

- Drag a page corner, click the arrows, swipe, or use the ← → keys to turn pages
- Jump to a section from the menu or the thumbnail strip
- Use the magnifier to read a page at full size
- Link to a specific page with `#page-N` (e.g. `index.html#page-5`)

## Files

- `index.html` — the reader
- `pages/` — the 12 booklet pages (front cover, pages 2–11, back cover)
- `pages/thumbs/` — small thumbnails for the page strip
